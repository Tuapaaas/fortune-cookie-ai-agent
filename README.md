A fortune-cookie fortune for an AI agent — the classic "tall, dark stranger" prophecy, except the stranger waiting in production is your own code, and it no longer knows you.

> You will meet a tall, dark stranger in production — it is your own code, and it no longer knows you.

## Run it

```sh
node main.ts
```

`main.ts` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/entry.txt`).
